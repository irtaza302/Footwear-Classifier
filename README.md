# Footwear Classifier

A deep learning model that classifies different types of footwear (shoes, sandals, and boots) using ResNet152V2 architecture, achieving 97% accuracy.

## Overview

This project implements a convolutional neural network (CNN) based classifier that can distinguish between different types of footwear. It uses the powerful ResNet152V2 architecture with transfer learning to achieve high accuracy in footwear classification.

## Model Details

- **Architecture**: ResNet152V2
- **Accuracy**: 97%
- **Classes**: 
  - Shoes
  - Sandals
  - Boots

## Getting Started

### Prerequisites

- Python 3.x
- TensorFlow 2.x
- Keras
- Other dependencies (specified in the notebook)

### Usage

1. Clone this repository
2. Open the Jupyter notebook `shoe-sandal-boot-classifier-resnet152v2-acc-97.ipynb`
3. Follow the instructions in the notebook to:
   - Load and preprocess the data
   - Train the model
   - Make predictions
